## 📌 Overview
English Janala is an interactive English vocabulary learning app. Users can select levels, view word cards, check word details in a modal, listen to pronunciation, search words.

---

## 🌐 Live Site:
🔗 https://mahdihasanprogrammer.github.io/m-29-english-janala/

---
## 💻 GitHub Repo:
🔗 https://github.com/mahdihasanprogrammer/m-29-english-janala.git

---

## 🛠 Tech Stack
- HTML  
- CSS (Tailwind CSS & DaisyUI via CDN)  
- JavaScript (Vanilla)

---

## ✨ Main Features
- 🎯 Select levels and highlight active level  
- 🃏 Display word cards with meaning & pronunciation  
- 🔍 Search functionality for words  
- 🔊 Voice pronunciation of words  
- 💖 Save words in a Saved section using Heart icon  
- 🔄 Modal to show word details: pronunciation, example sentence, synonyms  
- ⏳ Loading spinner while fetching data  
- ✅ Fully responsive design  

---

## 📦 Dependencies
- No npm packages required (Tailwind CSS & DaisyUI included via CDN)
